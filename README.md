# Let.Swap.cs

**Let.Swap** — это легковесная кроссплатформенная утилита для мгновенного исправления текста, набранного в неправильной раскладке, а также для быстрой смены регистра. Работает в фоновом режиме и вызывается глобальными горячими клавишами в любом приложении.

## 🚀 Основные возможности

*   **Транслитерация (RU ↔ EN):** Мгновенно превращает `ghbdtn` в `привет` (и наоборот).
*   **Смена регистра:** Перевод выделенного текста в ВЕРХНИЙ, нижний или оБРАТНЫЙ регистр.
*   **Глобальные горячие клавиши:** Работает поверх любых окон (браузер, текстовый редактор, мессенджеры).
*   **Системный трей:** Программа не занимает место на панели задач и тихо висит в трее.
*   **Сохранение настроек:** Выбранные комбинации клавиш сохраняются в JSON-файл и не сбрасываются после перезапуска.
*   **Кроссплатформенность:** Поддержка Windows, Linux (X11 и Wayland) и macOS.

## 📥 Скачать готовую версию

Вам **не нужно** устанавливать .NET или какие-либо библиотеки. Программа собирается в один независимый исполняемый файл (Self-contained).

1. Перейдите в раздел **[Releases](https://github.com/RomanSerj/Let.Swap.cs/releases)**.
2. Скачайте файл для вашей операционной системы:
   *   **Windows:** `Let.Swap-Windows.exe`
   *   **Linux:** `Let.Swap-Linux`
3. Запустите файл (на Linux предварительно может потребоваться `chmod +x Let.Swap-Linux`).

## ⌨️ Использование по умолчанию

После первого запуска программа свернется в системный трей. По умолчанию назначены следующие комбинации:

| Действие | Горячая клавиша |
| :--- | :--- |
| **Транслитерация** | `Alt + Z` |
| **Верхний регистр** | `Alt + X` |
| **Нижний регистр** | `Alt + Q` |
| **Обратный регистр** | `Alt + B` |

*Выделите текст в любой программе, нажмите нужную комбинацию, и текст мгновенно изменится. Изменить комбинации можно в окне настроек (двойной клик по иконке в трее).*
